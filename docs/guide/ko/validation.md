- 성공한 유료 스모크 테스트 한 번에는 테스트용으로 명시적으로 선택한 **gpt-6-luna / medium**을 사용했습니다. 제공한 합성 `sum.ts`는 합계를 반환하라는 요구 사항과 달리 `a - b`를 반환했습니다. 모델은 2행을 지적하며 `5` 대신 `sum(3, 2) = 1`이 되는 반례를 제시했습니다. 이 지적은 제공한 소스와 직접 대조하여 확인했습니다.
