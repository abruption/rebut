## unknown 結果の診断

新たに処理した `unknown` 結果には、許可リスト内の `unknown_reason` と `provider_elapsed_ms` が含まれます。タイムアウト、通信・本文読み取りエラー、サイズ・JSON・文字コード制限、モデル・使用量の不一致を区別し、例外文字列や応答本文は保存しません。本文処理が失敗しても、受信済みの安全なプロバイダー要求 ID と HTTP エラー状態は保持します。経過時間はアプリ側の観測値であり、プロバイダーの実行や課金完了の証明ではありません。過去の記録で欠落したメタデータは復元できません。unknown の予約額と同時実行枠は保持され、診断の追加によって制限時間延長・自動再試行・予約解除は行いません。

`unknown_reason` は処理が停止した箇所を示します。`upstream_status` もある場合、HTTP エラーを観測した後、本文の待機中に制限時間へ達した可能性があります。両方を合わせて解釈してください。過去の記録や防御的なエラー経路では診断フィールドが省略される場合があります。
