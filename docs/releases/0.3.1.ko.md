# Rebut 0.3.1

OpenAI 독립 리뷰의 기본 프로필이 GPT-6.2 Astra로 바뀌었습니다. 로컬 doctor의 버전 표시를 일치시키고 npm 발행 절차를 수정했습니다.

- 기본 제공 `astra-medium`은 `gpt-6.2-astra`와 medium 추론을 사용합니다. 짧은 컨텍스트 Standard 요율은 100만 토큰당 입력 $8, 출력 $40입니다. [모델 및 요금](https://developers.openai.com/api/docs/models/gpt-6.2-astra) · [#42](https://github.com/abruption/rebut/pull/42)
- `rebut --version`과 로컬 `doctor --connect`의 MCP 클라이언트가 같은 패키지 버전을 사용합니다. [#37](https://github.com/abruption/rebut/pull/37)
- npm 발행 워크플로가 검증된 tarball을 명시적인 로컬 경로로 전달합니다. [#28](https://github.com/abruption/rebut/pull/28)
- 저장소의 Issue-first 검사가 기본 브랜치의 메타데이터 검사로 전환됐습니다. 별도 GitHub 설정으로 적용하는 이벤트 정책 선언과 운영 절차도 추가했습니다. [#34](https://github.com/abruption/rebut/pull/34) · [#40](https://github.com/abruption/rebut/pull/40)

기존 Worker와 저장된 로컬 프로필 오버라이드를 전환하려면 [설정 안내](../guide/ko/configuration.md)를 따라 현재 리비전을 확인하고 모델과 요율을 함께 갱신하세요. 클라이언트가 이전 모델을 명시적으로 선택했다면 해당 설정도 갱신하세요. npm 설치와 운영 Worker 프로필 변경은 각각 적용합니다.
