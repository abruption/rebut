# Rebut 0.1.0 — 최초 공개 릴리즈

npm 패키지 `rebut-mcp`의 최초 정식 버전입니다. 실행 명령은 `rebut`이며 Node.js 24 이상이 필요합니다. MIT 라이선스로 공개했습니다.

npm 발행일은 **2026년 11월 13일**입니다(01:03:25 UTC / 10:03:25 KST). 이 문서는 당시 배포된 [0.1.0 패키지](https://www.npmjs.com/package/rebut-mcp/v/0.1.0)와 포함 문서를 기준으로 작성한 사후 릴리즈 기록입니다. GitHub 릴리즈 생성일이나 Git 태그를 발행일로 간주하지 않습니다.

## 주요 기능

- 직접 호스팅한 Cloudflare Worker에 연결하는 CLI와 로컬 stdio MCP 브리지
- `review`와 메타데이터 조회용 `review_status` 도구
- 명시한 파일·diff·요구사항 수집, 흔한 비밀 패턴 마스킹, SHA-256으로 검토 자료 고정
- 파일·행 근거를 포함한 구조화된 검토 결과와 모델·사용량·예상 비용 반환
- D1의 원자적 예산 예약, 인증 주체별 요청 ID 중복 방지, 불확실한 실행의 예약 유지
- macOS Keychain, Vaultwarden(`bw-get`), 환경변수 자격증명 백엔드의 명시적 선택
- Codex MCP 등록과 유료 검토를 수행하지 않는 `doctor --connect`
- CLI 모델·추론 환경설정과 별도 관리자 인증을 사용하는 서버 프로필 관리
- 한국어·영어·중국어 간체·일본어 사용자 문서

모델에는 저장소 복제, 셸·테스트 실행, 파일·PR 수정 권한을 제공하지 않습니다. 코드·리뷰 원문·키는 D1 장부에 저장하지 않습니다.

## 0.1.0 설치 방식

이 버전은 **사용자 소유 Worker와 D1 배포가 필요**합니다. 별도 Worker 없이 OpenAI API 키만으로 실행하는 로컬 검토 모드는 0.2.0에서 추가합니다.

```sh
npm install -g rebut-mcp@0.1.0
rebut set endpoint https://YOUR_HOST/mcp
rebut set token
rebut setup --client codex
rebut doctor --connect
```

macOS 예시이며 `set token`은 접속 토큰을 숨김 입력으로 받아 Keychain에 저장합니다. OpenAI API 키는 Worker에 설정하며, Worker 접속 토큰·관리자 토큰과 구분합니다. 공개 패키지는 개인 Worker나 OpenAI 크레딧 접근 권한을 제공하지 않습니다.

## 알려진 한계와 후속 변경

- 초기 Worker 소스의 공급자 대기 제한은 45초이며, npm 0.1.0 클라이언트의 도구 호출 제한은 65초입니다. Worker는 npm 패키지와 별도로 배포하므로 실제 서버의 제한은 배포 소스에 따릅니다. 긴 검토를 위한 30분 공급자 제한과 외부 계층의 여유 시간은 0.2.0에 포함됩니다.
- `review_status`는 검토 본문을 재생하지 않습니다. 최초 성공 응답을 보관해야 합니다.
- timeout/unknown은 실패나 미과금을 확정하지 않습니다. 같은 요청 ID로 상태를 확인하며, 자동 재실행·예약 해제를 하지 않습니다.
- 원장은 해당 Worker 배포의 Rebut 사용량을 관리하며 OpenAI 계정 전체의 사용량·잔액을 합산하지 않습니다. 예상 비용은 실제 청구서가 아닙니다.
- 흔한 비밀 패턴의 마스킹은 모든 비밀 제거를 보장하지 않습니다. 전송 자료를 확인해야 합니다.

0.1.1은 중간 개발 버전이며 이 기록 작성 시 npm에 발행되지 않았습니다. 다음 릴리즈 후보는 [0.2.0](0.2.0.ko.md)입니다.
