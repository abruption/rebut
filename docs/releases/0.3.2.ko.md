# Rebut 0.3.2

지적사항이 0건이어도 어떤 수락 기준을 검토했고 어떤 기준은 미평가로 남았는지 구분하기 쉽도록 리뷰 안내와 기본 지침을 보완했습니다.

- 번들에 식별 가능한 수락 기준이 있으면, OpenAI·Anthropic 공통 리뷰 지침이 검토한 기준과 근거, 미평가 기준을 `summary`에 적도록 요청합니다. 판단에 필요한 파일이나 테스트는 `additional_evidence`에 요청합니다. [#51](https://github.com/abruption/rebut/pull/51)
- 네 언어의 설치 안내에서 사람이 승인한 기준을 패치와 별도로 고정하고, 마스킹된 번들을 제출 전에 원문과 대조하는 예제를 제공합니다. [#49](https://github.com/abruption/rebut/pull/49) · [한국어 안내](../guide/ko/installation.md)
- 기준별 요약은 리뷰어의 보고입니다. 호출자가 승인된 기준 및 실제 근거와 대조하며, 기준이나 근거가 빠졌다면 지적사항이 없어도 미평가로 취급합니다. 수락과 병합은 기존 승인 절차를 따릅니다.

기존 번들과 응답 형식을 사용합니다. 로컬 실행에는 CLI 업데이트가, Worker 모드에는 서버 코드 배포가 필요합니다. 연결이 끊겨 결과가 불확실하면 같은 백엔드에서 기존 요청 ID로 상태를 확인하세요.
