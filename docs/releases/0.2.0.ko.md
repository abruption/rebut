# Rebut 0.2.0 — 릴리즈 후보

**2026년 11월 13일 문서 작성 시점: 발행 준비 중.** 아래 내용은 0.2.0 후보 소스의 변경 내역입니다. 실제 발행 결과는 [npm 레지스트리](https://www.npmjs.com/package/rebut-mcp/v/0.2.0)와 [GitHub 릴리즈](https://github.com/abruption/rebut/releases)에서 확인하세요. 이 문서 자체는 운영 Worker 배포나 기존 설치 업데이트의 완료 기록이 아닙니다.

GitHub 저장소 이름은 `abruption/rebut`입니다. npm 패키지는 `rebut-mcp`, 실행 명령은 `rebut`을 유지합니다. Node.js 24 이상이 필요합니다. 0.1.0에서 바로 업그레이드하는 버전이며, 미발행 중간 버전 0.1.1의 변경을 포함합니다.

## 로컬 실행을 기본으로 제공

새 설치는 Cloudflare 없이 로컬 stdio MCP 서버에서 자신의 OpenAI API 키로 검토합니다. 별도의 HTTP 서버나 수신 포트를 열 필요가 없습니다. 검토 자료는 OpenAI API로 전송합니다.

로컬 SQLite 원장은 예산 예약·요청 중복 방지·사용량 메타데이터를 재시작 후에도 보존합니다. 코드·리뷰 원문·키는 장부에 저장하지 않습니다. Cloudflare Worker와 D1은 여러 기기가 하나의 원장을 공유하는 선택적 백엔드로 계속 지원합니다.

- 기존 endpoint 설정이 있는 사용자는 Worker 모드를 유지합니다.
- `rebut set mode local|worker`로 명시적으로 선택합니다. `rebut set endpoint URL`도 Worker 모드를 선택합니다. 장애 시 다른 백엔드로 자동 대체하지 않습니다.
- 새 로컬 원장의 기본값은 UTC 하루 $6.66·월 $200·요청당 $6.66, 동시 미해결 요청 1개, 하루 신규 요청 100건입니다.
- 로컬 한도는 해당 기기의 데이터 디렉터리 단위입니다. 다른 Mac·Worker·OpenAI 계정 사용량과 합산하지 않습니다.
- 백엔드 전환은 기존 요청·예약을 이전하거나 해제하지 않습니다. unknown 요청을 다른 백엔드에서 새 ID로 우회 재실행하지 마세요.

## 긴 검토와 불확실한 결과 처리

- 공급자 대기 상한을 **1,800초(30분)**로 늘립니다.
- HTTP·MCP 클라이언트는 **1,830초**, Codex 도구 제한은 **1,860초**로 설정해 공급자 결과와 장부 처리를 기다릴 여유를 둡니다. 초기 접속 제한은 별도입니다.
- npm CLI·stdio 브리지·소스 실행 클라이언트와 저장소의 `scripts/bw-client.py` 경로가 같은 연결 구현을 사용합니다. Node HTTP의 별도 기본 제한도 조정합니다.
- 원문 없이 확인 가능한 unknown 원인·경과 시간 등 제한된 진단 메타데이터를 보강합니다. 자동 유료 재시도는 추가하지 않습니다.
- 기본 설정에서는 unknown 한 건이 신규 검토를 막을 수 있습니다. [로컬 복구와 제한된 용량 추가](../guide/ko/operations.md#로컬-복구와-제한된-용량-추가)에 따라 원래 예약을 유지하고 운영자 근거로 판단하세요.
- 로컬 `rebut status --pending`으로 원래 요청 ID를 잃었을 때 미해결 요청을 조회할 수 있습니다. 일반 `rebut status ID`는 키 없이 로컬 메타데이터를 조회합니다.
- SIGINT/SIGTERM 취소는 가능한 범위에서 진행 중 요청을 unknown으로 기록하고 예약을 유지합니다. 요청이 공급자에 전달됐다면 과금됐을 수 있습니다. 강제 종료·장애 뒤 남은 불확실한 실행의 예약과 슬롯을 자동 해제하지 않습니다.

30분은 클라이언트와 공급자 호출의 대기 설정입니다. 네트워크·MCP 호스트·운영 환경의 종료나 취소에도 결과 전달을 보장하는 것은 아닙니다. 최초 결과를 받지 못했다면 같은 요청 ID로 상태를 확인하세요. 다른 MCP 호스트도 긴 검토를 위해 도구 제한을 1,860초 이상으로 설정해야 하며, 이를 지원하지 않으면 먼저 연결이 종료될 수 있습니다. 검토 본문 재생은 지원하지 않습니다.

## 자격증명과 운영 CLI

OpenAI API 키, Worker 접속 토큰, Worker 관리자 토큰을 별도 역할로 관리합니다. Keychain·Vaultwarden·env 백엔드는 명시적으로 선택하며 자동 대체하지 않습니다.

- 로컬 OpenAI 키: `rebut set api-key`(macOS Keychain 숨김 입력)
- env 기본 변수: `REBUT_OPENAI_API_KEY`. 공용 `OPENAI_API_KEY`는 `rebut set api-key-env OPENAI_API_KEY`로 명시적으로 선택
- 로컬 예산: `set daily-budget`, `set monthly-budget`, `set request-budget`
- 로컬 동시 실행 상한: `set max-concurrent`(1–10). 변경해도 기존 예약·비용·unknown 상태는 해제되지 않음
- 로컬 프로필은 OS 소유자가 관리하며, Worker 프로필은 기존 관리자 인증을 사용

## 업그레이드 안내

**아래 설치 명령은 npm 0.2.0 발행 후 사용합니다.**

```sh
npm install -g rebut-mcp@0.2.0
rebut setup --client codex --replace
```

0.2.0 전용 설정을 쓰기 전에 기존 `config.json`을 백업하세요. 0.1.0은 새 설정 필드를 거부하므로 Worker 사용자도 다운그레이드 시 이전 설정의 복원이 필요할 수 있습니다. 장부는 별도로 보존하며 백업 설정에 맞춘다는 이유로 삭제하지 마세요.

별도 Codex home을 사용하면 `--codex-home PATH`를 지정하고, 사용자 지정 `REBUT_CONFIG_DIR`이 있다면 setup을 실행하는 셸에도 같은 값을 설정하세요. `setup --replace` 전에 `config.toml` 전체를 백업하고 결과를 비교하세요. Rebut 등록을 갱신하며 TOML 형태에 따라 파일 전체를 다시 직렬화할 수 있어 주석·서식이 달라질 수 있습니다. 직접 관리하는 Codex 등록의 `tool_timeout_sec`는 1,860초 이상으로 맞춥니다. MCP 호스트를 완전히 재시작한 뒤 `rebut doctor --connect`로 확인합니다. 이 명령은 유료 검토를 실행하지 않습니다.

기존 Worker 사용자는 먼저 CLI를 업데이트하고 MCP 등록·호스트 재시작을 완료한 뒤 Worker를 업데이트합니다. CLI 업데이트만으로 운영 Worker의 공급자 제한이 바뀌지 않습니다. Worker 소유자는 저장소 소스와 자신의 비공개 설정을 사용해 별도로 배포해야 합니다. 0.2.0에 새 D1 마이그레이션은 없으며 기존 `0001`·`0002`를 사용합니다. 아직 적용하지 않은 마이그레이션이 있다면 설치 가이드에서 먼저 확인하세요.

로컬 모드를 선택하려면 별도로 설정합니다(macOS Keychain 예시).

```sh
rebut set mode local
rebut set api-key
rebut setup --client codex --replace
```

상태 조회에도 MCP 호스트와 같은 `REBUT_CONFIG_DIR`을 사용하세요. 다른 디렉터리의 `not_found`는 미실행의 근거가 아닙니다.

이후 MCP 호스트를 재시작하고 `rebut doctor --connect`로 확인하세요. 설치·전환·등록 제거 과정에서 기존 설정·키·요청 장부를 임의로 삭제하거나 초기화하지 마세요.

## 검증 범위와 제한

타입 검사·CLI/Worker 빌드·자동화 테스트·설치된 npm tarball smoke를 발행 전에 확인합니다. 공급자는 모의 처리하며 자동 검증은 유료 모델을 호출하지 않습니다. CI는 Node.js 24/26과 macOS/Ubuntu 조합을 사용합니다. Windows 동작·ACL은 검증하지 않았습니다. 30분 전체를 기다리는 실환경 검토 완료를 검증한 것은 아닙니다. 로컬 doctor의 성공은 OpenAI 계정의 모델 사용 권한·잔액·실제 검토 품질을 입증하지 않습니다.
