# Rebut 0.6.1

일일 지출 한도를 해제할 수 있고, GPT-6.2 Astra와 Claude Fable 5.2의 출력 상한을 최대 50,000토큰으로 설정할 수 있습니다.

## 예산

- macOS와 Linux의 로컬 모드에서는 `rebut set daily-budget 0`으로 일일 지출 한도를 해제하고 `rebut set monthly-budget USD`로 월간 한도를 지정할 수 있습니다. Windows를 포함한 모든 플랫폼의 로컬 모드에서는 `REBUT_LOCAL_BUDGET_LIMITS` 환경변수로 두 한도를 설정할 수 있습니다. 기존 MCP 등록에서 이 환경변수를 쓰려면 Codex 또는 Claude Code의 등록에 전달 항목을 추가하세요. [설정](../guide/ko/configuration.md) · [#107](https://github.com/abruption/rebut/issues/107)
- 0.6.1 Worker에서는 `REBUT_BUDGET_LIMITS` 바인딩을 사용합니다. 환경변수와 바인딩에 사용하는 JSON에는 `dailyMicrousd`, `monthlyMicrousd` 또는 둘 다를 지정할 수 있습니다. 금액 단위는 백만분의 1달러입니다. 일일 한도를 해제해도 월간·요청별 지출 한도, 일일 요청 수, 동시 실행 한도는 계속 적용됩니다. [#104](https://github.com/abruption/rebut/pull/104)
- 두 모드 모두 `rebut budget`으로 일일·월간 지출 한도를 확인할 수 있습니다. Worker를 갱신할 때는 기존 D1 데이터베이스와 인증 설정을 사용하세요. D1 스키마 변경은 없습니다. 로컬 설정 파일에 일일 한도 `0`을 저장했다면 0.6.0으로 되돌리기 전에 양수로 바꾸세요.

## 출력 상한과 업데이트

- 로컬 모드와 Worker 모두 GPT-6.2 Astra와 Claude Fable 5.2 프로필에 `--max-output-tokens 50000`을 지정할 수 있습니다. Fable 프로필에는 `--provider anthropic`을 함께 지정하세요. 다른 모델의 상한은 16,384토큰이며 기존 프로필은 설정한 값을 유지합니다. 출력 상한을 높이면 예약 비용도 늘어납니다. [#104](https://github.com/abruption/rebut/pull/104)
- 0.6.0 CLI는 응답에 16,384토큰을 초과하는 프로필이 하나라도 있으면 목록 전체를 읽지 못합니다. 해당 Worker를 쓰는 CLI를 먼저 갱신한 뒤 프로필의 출력 상한을 높이세요. 전역 npm 설치본은 `rebut update`로 갱신하고 MCP 호스트를 다시 시작하세요. [설치와 사용](../guide/ko/installation.md)
