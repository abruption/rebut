# Rebut 0.6.1

Worker의 일일 지출 한도를 해제할 수 있고, GPT-6.2 Astra와 Claude Fable 5.2의 출력 상한을 최대 50,000토큰으로 설정할 수 있습니다.

## Worker 예산

- 0.6.1 Worker의 `REBUT_BUDGET_LIMITS` 바인딩에서 일일·월간 지출 한도를 따로 지정할 수 있습니다. JSON에 바꿀 항목을 넣고 금액은 백만분의 1달러 단위로 적습니다. `dailyMicrousd`를 `0`으로 설정하면 일일 지출 한도가 해제됩니다. 월간·요청별 지출 한도, 일일 요청 수, 동시 실행 한도는 계속 적용됩니다. [설정](../guide/ko/configuration.md) · [#104](https://github.com/abruption/rebut/pull/104)
- Worker를 갱신할 때 기존 D1 데이터베이스와 인증 설정을 그대로 사용하세요. D1 스키마 변경은 없습니다. 배포 후 `rebut budget`으로 적용된 일일·월간 지출 한도를 확인할 수 있습니다.

## 출력 상한과 업데이트

- Worker를 갱신하면 GPT-6.2 Astra와 Claude Fable 5.2 프로필의 `maxOutputTokens`를 최대 50,000토큰으로 설정할 수 있습니다. 다른 모델의 상한은 16,384토큰이며 기존 프로필은 설정한 값을 유지합니다. 출력 상한을 높이면 예약 비용도 늘어납니다. [#104](https://github.com/abruption/rebut/pull/104)
- 0.6.0 CLI는 응답에 16,384토큰을 초과하는 프로필이 하나라도 있으면 목록 전체를 읽지 못합니다. 해당 Worker를 쓰는 CLI를 먼저 갱신한 뒤 프로필의 출력 상한을 높이세요. 전역 npm 설치본은 `rebut update`로 갱신하고 MCP 호스트를 다시 시작하세요. [설치와 사용](../guide/ko/installation.md)
