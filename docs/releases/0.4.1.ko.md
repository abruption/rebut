# Rebut 0.4.1

Windows에서 OpenAI API 키를 환경변수로 전달해 로컬 MCP를 사용하는 방법을 안내합니다. 네 언어의 문서를 다듬고 npm 게시 결과와 공개 파일 검증 결과를 따로 기록하도록 발행 절차를 변경했습니다.

- Windows x64와 Node 24에서 모의 응답으로 패키지 설치, MCP 연결, 재시작 후 SQLite 상태 조회를 확인했습니다. Windows 10 기기에서는 기존 0.4.0 패키지로 로컬 MCP에 직접 연결해 합성 코드의 OpenAI 검토 한 건을 완료했습니다. 같은 버전의 MCP를 Windows Codex App Server에서 띄워 도구를 호출하는 경로는 모의 응답으로 확인했습니다. [#79](https://github.com/abruption/rebut/pull/79) · [#82](https://github.com/abruption/rebut/pull/82)
- 한국어·영어·일본어·중국어 간체 문서에서 요청 ID의 중복 방지 조건과 `doctor` 출력을 명확히 하고, 직역투와 반복을 줄였습니다. [#77](https://github.com/abruption/rebut/pull/77)
- npm 공개 파일의 해시와 provenance를 게시 성공 후 별도 작업에서 확인합니다. 레지스트리 반영이 늦어 검증이 실패하면 해당 작업만 다시 실행할 수 있습니다. [#75](https://github.com/abruption/rebut/pull/75)

Windows에서는 `config.json`이 없는 전용 데이터 디렉터리와 프로세스 환경변수를 사용합니다. 영구 설정 파일의 읽기·쓰기는 파일 권한 검증을 지원할 때까지 차단됩니다. Worker 모드와 Codex·Claude Code의 대화형 앱 연결은 별도 검증이 필요합니다. 기존 설치를 갱신하거나 Windows에서 처음 설정하려면 설치 안내를 참고하세요. [Windows 설치 안내](../guide/ko/installation.md#windows-로컬-mcp-mvp)
