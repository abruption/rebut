# Rebut 0.6.2

Rebut이 리뷰 모델에 인용할 수 있는 파일 경로와 줄 범위를 알려줍니다. 코드 발췌를 Markdown으로 보내면 문서에 적힌 원본 위치와 실제로 인용할 수 있는 위치를 구분하도록 안내합니다. [#110](https://github.com/abruption/rebut/pull/110)

## 인용할 수 있는 범위

- OpenAI와 Anthropic 모두가 제출된 파일과 diff의 변경 후 줄 범위를 안내받습니다. 표준 출력과 확장 출력 v2 모두에 적용됩니다. 범위 목록이 길면 목록을 생략하고 근거와 인용 방법을 전달합니다.
- 원본 경로와 줄 번호를 인용하려면 원래 상대 경로로 파일을 제출하세요. 발췌를 직접 넣을 때는 `files[].path`에 원래 상대 경로를, `start_line`에 첫 줄 번호를 지정합니다. Markdown 문서를 제출하면 리뷰 모델에는 그 문서 자체의 경로와 실제 줄 번호를 인용하도록 안내합니다. [설치와 사용](../guide/ko/installation.md)

## 업데이트

npm으로 전역 설치한 경우 `rebut update`를 실행하고 Codex나 Claude Code를 다시 시작하세요. Worker 모드에서는 새 인용 안내를 적용하려면 Worker 코드를 업데이트하세요. 기존 D1과 인증 설정을 사용하며 별도의 D1 마이그레이션은 필요하지 않습니다. 기존 입력 형식으로 새 리뷰를 요청할 수 있습니다. 이미 보낸 요청의 상태는 원래 ID로 조회하세요.
